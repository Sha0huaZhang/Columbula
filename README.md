# Columbula

**Dormi cara columbula**~  
睡吧，睡吧，我的小鸽子~  
**O columbula mea**~  
睡吧，我亲爱的小鸽子呀~  
**Splendeat fenestra, adsint somnia flora**~  
愿繁花与美梦盛开在你窗边~  
**O cara filia lunae**~  
月亮的孩子呀，我的小鸽子~  
**Neve plumam pulvis foedet tuam**~  
即便尘埃玷染你洁白的羽毛~  
**Nec iam complexum alma**~  
即便你不再躺在温暖的怀抱~  
**Capias bona somnias a luna**~  
也愿你在梦中与月相伴而眠~~
